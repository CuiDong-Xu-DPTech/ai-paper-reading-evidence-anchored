# XRead 跨学科论文审读技能

## 1. 何时使用（触发条件）
满足任一即触发：
- 需要阅读一篇**不属于自己专业**或横跨多学科的 STEM 论文，并判断其方法/结论对本课题的适用性；
- 需要为跨学科组会准备可核验的论文汇报；
- 需要评估一篇论文的可信度（证据是否支撑结论）而非仅获其大意。

**不适用**：纯摘要浏览（用普通摘要即可）；需要复现计算结果的场景（用论文复现类技能）。

## 2. 输入与输出
**输入**：论文（PDF 或带页码文本导出，文本须含 `[第 N 页]` 标记）+ 任务声明
（用户背景/学科 + 要回答的问题，如"该方法能否用于我的 X 数据"）。
**输出**：审读报告（默认 `triage_report.md`，结构见 P4）+ `run_meta.json`
（元数据、质量门结果、锚点校验结果、引用覆盖率、各阶段耗时）。

## 3. 执行流程

### Q0 预检与体裁分类（强制第一步）
1. 若输入为 PDF：提取全文，统计每页字符数。
   **质量门 G0**：平均每页字符 <50 或总计 <500 → 判"无文字层/损坏"，
   转第 5 节降级流程。禁止凭图像或常识编造内容。
2. 记录元数据：标题/作者/期刊/页数/预印本标记（arXiv水印=预印本，须注明）。
3. **体裁判定**（三选一，写入报告头部）：
   - `定理证明型`：以定义-定理-证明为主干（数学、理论CS、部分统计）；
   - `实验型`：以测量-不确定度-对照为主干（物理实验、化学实验、生物实验、临床）；
   - `计算/数据分析型`：以数据集-模型-验证为主干（生物信息、ML应用、模拟、计算材料）。
   混合体裁（如理论+实验验证）须注明主次。
4. **学科判定**：数学/物理/化学/生物·医学/工程/计算科学（用于选取 D1 检查单；
   跨学科论文取主要贡献学科）。

### P1 速览（目标 5 分钟）
只读标题、摘要、图表标题、结论段。产出**速览卡**（≤150 字）：研究问题 → 核心主张
→ 证据类型组合 → 对用户任务的相关度（高/中/低+一句理由）。
**门 G1**：速览卡每条论断括注页码；写不出页码的删或标"待确认"。

### P2 学科规范核对（核心遍）
按体裁加载对应检查单（见第 4 节 D1−D3），构建**主张-证据-页码对齐表**（3−6 行）：

`| 主张 | 证据类型 | 学科规范项核查 | 页码 | 标注 |`

- 证据类型从该体裁的规范词汇中选（如实验型：测量/对照/统计检验/不确定度分析）；
- 标注三级强制：`[事实]`（原文明确+页码可定位）`/ [推断]`（多处综合，列依据页码）
  `/ [不确定]`（信息不足，说明缺什么）；
- **门 G2**：`[事实]` ≥ 半数；全部页码锚点用 `scripts/verify_anchors.py` 校验通过。

**引用完整性自查**（v2.1.0 新增，配套陷阱 G-E）：报告主体完成后统计**实际引用页码数
÷ 全文页数**的覆盖率；长文（≥20 页）覆盖率 <50% 时必须自查并输出**盲区警告清单**
（哪些页段/章节/图表从未被引用），补读关键盲区或在报告"适用边界"中显式声明覆盖
边界。覆盖率与清单写入 run_meta.json。

### P3 跨学科陷阱扫描
从 `pitfalls.md` 陷阱库选取本体裁高发陷阱 2−4 个，逐个对照本文：
- 是否存在该陷阱的误读风险？（举出具体位置与页码）
- 本文哪些表述容易被外行误读？
产出"易误读点"清单（这是跨学科阅读的核心增值，不可省略）。
v2.1.0 提示：体裁新增项优先纳入候选——定理证明型 T5（化归策略盲区）、实验型
E6−E9（缩放因子/拟合三分/N 层级/exploratory）、计算型 C6−C7（ICC 双分母/
抽样框架）。

### P4 组装与自检
报告结构：①速览卡 ②主张-证据-页码对齐表 ③适用边界与学科局限
（作者自述局限 + 学科固有局限两层）④对用户任务问题的明确回答
（适用/部分适用/不适用/证据不足 + 推理链 + 2−4 条后续阅读方向，
引文文献未读时写"查找建议"）。
**幻觉自检**：逐条回看 `[事实]`，用 `verify_anchors.py --quotes` 校验；
不符即修正或降级。**自换算数字甄别**（v2.1.0 落实，配套陷阱 G-F）：凡模型自行
换算的数字（单位换算/口径转换/量级折算）不得列为原文引文，必须标 `[推断]` 并附
换算式。写入 run_meta.json。

## 4. 学科检查单（P2 按体裁加载）
- **D1 定理证明型**（详细版见 discipline/theorem_proving.md）：
  主定理编号与陈述是否完整抄录｜**证明策略骨架（v2.1.0 强制）：化归到什么、用什么
  技术桥接（如张量幂/Kronecker 幂把多变元化归到单变元已有理论），显式写出并锚定
  页码**｜假设/条件与结论是否分离｜证明是完整的还是引用归纳（"proof postponed"/
  引理推迟）｜证明依赖链｜记号是否在首次使用处定义｜"猜想/假设"与"已证"是否区分。
- **D2 实验型**（详细版见 discipline/experimental.md）：
  数值结果是否带不确定度/误差｜**表头缩放因子（×10⁻⁴ 类）是否连数抄录**｜
  **拟合值/实测值/模拟输入值三分**｜样本量/重复次数是否报告｜对照条件是什么｜
  统计检验方法与多重比较校正｜**多装置数据是否分源**｜系统误差是否讨论｜
  表征完整性（化学）/预注册（临床）。
- **D3 计算/数据分析型**（详细版见 discipline/computational.md）：
  数据来源与规模｜**ICC/方差占比的分母口径（表型方差 vs 遗传方差）**｜
  **抽样框架偏差（选样是否围绕已知位点偏斜）**｜模型假设是否声明｜验证方式
  （holdout/交叉/外部集）｜基准与消融是否存在｜多重检验｜代码与数据可用性声明｜
  观察数据 vs 实验数据。
（单科论文可只加载对应单，但跨学科对照问题须同时检查两单的交叉项。）

## 5. 降级与停止条件
| 情形 | 动作 |
|------|------|
| G0 失败（无文字层/损坏） | **停止精读**。输出 status_report.md：异常类型、已尝试动作
（文本提取统计）、无法继续原因；建议用户提供文本版或允许 OCR。禁止输出任何"审读报告"式内容。 |
| 体裁无法判定 | 输出候选体裁并按最接近单执行，报告头部声明不确定性。 |
| 锚点校验失败 | 论断降级 `[不确定]` 或删除；不得保留错误锚点。 |
| 引用覆盖率 <50%（长文） | 不判失败：输出盲区警告清单，由报告读者决定是否要求补读。 |
| 任务缺失 | 按"跨学科组会审读"默认模板，run_meta.json 注明。 |

## 6. 适用边界
- STEM 实验与理论研究；人文社科论文体裁判定与检查单未验证；
- 依赖可提取文本层（扫描件需先 OCR，本技能不含）；
- 页码锚点基于文本导出标记，与 PDF 物理页一致；重排版工具可能改变页码；
- 学科判定基于文本特征，边缘案例可能误判（报告会声明置信度）；
- 不替代领域专家判断；`[推断]`/`[不确定]` 项须人工复核。

## 7. 配套资源
- `pitfalls.md`：四学科高发误读陷阱库（P3 使用，v2.1.0 增至 27 项含 G-E/G-F）；
- `discipline/theorem_proving.md`、`discipline/experimental.md`、
  `discipline/computational.md`：体裁检查单详解；
- `scripts/export_pdf_text.py`：PDF→带页码文本；`scripts/verify_anchors.py`：
  锚点与引文校验；`scripts/checklist_scorer.py`：gold checklist 自动预检。
