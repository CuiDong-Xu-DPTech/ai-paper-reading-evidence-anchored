# 跨学科误读陷阱库（P3 步骤使用）

每个陷阱含：名称/识别信号/误读/正确做法。P3 选最相关 2−4 个，对照位置（带页码）产出"易误读点"。

## 定理证明型高发陷阱
- **T1 条件隐没**：转述时丢前提。信号："若/假设/设"。正确：条件与结论分开抄录锚定。
- **T2 例子当证明**：motivating example 当一般论证。信号：example/illustration。
  正确：定位真正的 Proof 环境。
- **T3 引理依赖链断裂**：关键引理被跳读，以为证明"很短"。信号：引用的 Lemma 编号。
  正确：画定理→引理→已知依赖链。
- **T4 猜想当结论**：conjecture 当已证。信号：conjecture/we expect/plausible。
  正确：标 [不确定] 注明"未证"。
- **T5 化归策略盲区**（v2.1.0 新增）：主定理的化归路线（如张量幂/Kronecker 幂把
  多变元化归到单变元已有理论）被整体跳过——双评委盲测 4/4 报告同漏此点。
  信号：证明概览的 reduce to / it suffices to / 构造 X 的幂。
  误读：说不出"化归到什么、怎么桥接"，把刚性/排除性结果当构造性算法。
  正确：写出证明策略骨架并锚定构造所在页（见 D1）。

## 实验型高发陷阱
- **E1 无不确定度比较**：忽略误差范围比数值。信号：±、error bar。
  正确：区间重叠不得称"显著提升"。
- **E2 校准值当结果**：仪器参数/校准读数当实验发现。信号：calibration/set to。
  正确：区分输入参数与输出结果。
- **E3 方案当实验**：proposal 当已完成测量。信号：将来时态、simulation-only。
  正确：核对 Results 是否有对应数据。
- **E4 单点当普适**：单一条件/样品外推为规律。信号：无重复实验节。
  正确：标注适用范围。
- **E5 相关当因果**（实验版）：观测共变说成机制。信号：correlates/associated。
  正确：查有无干预或机理实验。
- **E6 表头缩放因子漏抄**（v2.1.0，物理档案）：表内数值脱离表头缩放被引用
  （如表头 ×10⁻⁴ 下的 742.4 被当独立数值，量级读错）。
  信号：表头含 ×10⁻ⁿ/per unit/%（单位）。正确：抄数值必连同缩放因子；
  换算后标 [推断] 并附换算式。
- **E7 拟合值/模拟输入当实测**（v2.1.0，物理档案）：级联拟合提取值（99.5% 保真
  度=衰减拟合常数）当"直接测得"；"In the simulation, we consider…" 后的参数当
  论文新测结果；另一台装置（40Ca⁺ 交叉验证绿点）的数据被混入主数据源。
  信号：fit/decay constant/simulation input；图注另一系统标注。
  正确：拟合值/实测值/模拟输入值三分标注；多装置数据分源核对，禁止混源平均。
- **E8 N 与统计单位错位**（v2.1.0，神经科学档案）：把统计量自由度当被试数
  （t(28) 的 28 是刺激对层面非 28 人）；只报一个 N 掩盖招募 N 与各分析最终 N
  不一（22/20/19）。信号：括号自由度、各分析 N 不一致。
  正确：提取招募 N/各分析 N/自由度单位三层并锚定。
- **E9 exploratory 当确认性**（v2.1.0，神经科学档案）：作者自标 exploratory
  的结果被当确认性结论；未校正 p 超出声明用途使用。
  信号：exploratory/uncorrected/one hypothesis is。
  正确：探索性结果降级转述；未校正 p 只作定义门槛，不作结论证据。

## 计算/数据分析型高发陷阱
- **C1 拟合当验证**：训练性能当泛化能力。信号：无 train/test 划分。
  正确：定位 holdout/CV/外部集并锚定。
- **C2 关联当因果**：观察数据的关联被解释为因果。信号：观察性设计。
  正确：因果语言只在有干预/孟德尔随机化时允许。
- **C3 数据库偏差隐没**：来源覆盖偏差被忽略。信号：公共库数据。
  正确：查是否声明 sampling bias。
- **C4 基准缺失**：无对比即称更优。信号：无 baseline 表。
  正确：标"未与 X 比较"为信息缺口。
- **C5 可复现性黑洞**：无代码/数据声明。信号：无 availability statement。
  正确：列为后续确认项。
- **C6 ICC 双分母混用**（v2.1.0，进化生物档案）：同一性状 ICC=0.34（占**表型
  方差**）与 63%（占**遗传方差**）被当同口径引用或互比；"88% of genetic
  variance" 与 ICC=0.082 并存并非矛盾——分母不同。
  信号：ICC / % of variance 必查同句分母定义。正确：先抄分母口径再引数，
  两口径不可互换（见 D3）。
- **C7 抽样框架偏斜**（v2.1.0，进化生物档案）：亚分析效应量骤变（宿主主效
  47%→35% 跌破交互项）仍被外推到自然种群——宿主系围绕已知抗性位点遴选，
  主效估计对亚集极端敏感。信号：sub-analysis / lines chosen around known
  loci / 子集 N 骤减。正确：核对选样框架；亚集敏感的估计标注外推边界（见 D3）。

## 通用陷阱（全体裁）
- **G-A 预印本当正式版**：arXiv 水印提示预印本，结论可能与正式版不同。
- **G-B 摘要过拟合**：只用摘要判断价值，遗漏方法节关键限制。
- **G-C 数字漂移**：摘要数字与正文/图表不一致，须交叉核对。
- **G-D 术语跨学科歧义**：同一词在不同学科含义不同（"model"/"validation"/
  "dimension"）。按本文领域定义理解并锚定。
- **G-E 引用盲区**（v2.1.0 新增）：长文跳读后"不知道自己没读过"。
  识别信号：报告实际引用页码数 ÷ 全文页数；长文（≥20 页）覆盖率 <50% 时必须
  自查。正确：列出从未被引用的页段清单，输出盲区警告；补读或显式声明覆盖边界。
- **G-F 自换算当引文**（v2.1.0 新增）：模型自行换算的数字（单位换算/口径转换/
  量级折算）被写成原文引用。信号：报告数字在原文 grep 不到一致形式。
  正确：自算数字必须标 [推断] 并附换算式（如 742.4×10⁻⁴≈7.4×10⁻²），
  禁止当原文引用。
