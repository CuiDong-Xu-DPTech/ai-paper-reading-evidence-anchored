# D2 实验型论文检查单

适用：物理实验、化学实验、生物实验、医学/临床、工程验证。
论证正确性判据：**测量可靠性**（不确定度控制 + 对照设计 + 可重复性）。

## 强制核查项
- [ ] **数值+不确定度**：每个结果数值是否带误差棒/不确定度/置信区间；
  无不确定度的关键数值标 `[不确定]`（缺什么：误差分析）。括号计数法 0.2(2)% = 0.2±0.2%。
- [ ] **表头缩放因子**（v2.1.0 新增，源自物理档案）：读任何表格先抄录表头单位与
  缩放因子（如 `Infidelity (×10⁻⁴)`），数值必须连同缩放一起抄录再解读。
  信号：表头含 ×10⁻ⁿ/per unit/%。误读示例：把表内 742.4（×10⁻⁴）读成 742.4%
  或 7.4×10⁻² 之外的数。漏抄缩放因子 = 全表数字错误一个量级以上。
- [ ] **拟合值/实测值/模拟输入值三分**（v2.1.0 强制，源自物理档案）：逐个关键数字
  标注来源类型——(a) 直接测量值（原始数据）；(b) 拟合提取值（如级联序列指数
  衰减拟合的衰减常数、99.5% 保真度是拟合提取非直接测量）；(c) 模拟输入值
  （"In the simulation, we consider…" 后的参数是喂给模型的假设，不是新测量结果，
  更不是论文贡献）。三类混引 = 把假设当证据。
- [ ] **多装置/多来源数据分离**（v2.1.0 新增，源自物理档案）：图中的数据点并非
  来自同一装置/系统——绿点可能来自另一台装置（如另一台 40Ca⁺ 系统的交叉验证点），
  须逐点核对来源标注；混源数据当同源平均会虚构一致性。
- [ ] **样本量/重复次数**：N 是多少（试次数、样品数、被试数）；单次测量是否说明。
- [ ] **对照条件**：实验与什么比较（空白对照/基准器件/安慰剂/阴性对照）；
  无对照的提升或效应只能标 `[不确定]`。
- [ ] **统计检验**：检验方法（t/ANOVA/贝叶斯因子…）、多重比较校正、显著性阈值。
- [ ] **测量 vs 推算**：区分直接测量值、拟合值、理论预言值、外推值——四类证据强度不同。
- [ ] **系统误差讨论**：是否列出系统误差源并评估；仅给统计误差不够。
- [ ] **仪器与方法关键参数**：影响结论的参数（温度/频率/浓度/曝光）是否报告。
- [ ] **领域专项**：化学=表征完整性（结构证据链）；临床=预注册与伦理；
  生物=独立重复与统计功效；物理=校准与稳定性。

## 外行高发误读（跨学科读者）
1. 忽略不确定度：把 0.95±0.20 和 0.97±0.01 当成"差不多"。
2. 把仪器校准值/参数设置/模拟输入当实验结果。
3. 把 proposal/方案设计当已完成实验（检查时态：will/proposed vs measured）。
4. 相关当因果；单变量提升当系统性能提升。
5. 忽略数据排除规则（outlier rejection）对结果的影响。
6. 表格数字不带表头缩放因子直接引用，量级读错。

## 页码锚点要求
核心结果数值、方法关键参数、误差分析段落、**表头缩放因子所在表头**各至少 1 个锚点。
