# D3 计算/数据分析型论文检查单

适用：生物信息、ML 应用、模拟/仿真、计算材料、大规模数据分析。
论证正确性判据：**方法有效性**（数据质量 + 模型假设 + 验证设计 + 可复现性）。

## 强制核查项
- [ ] **数据来源与规模**：数据从哪来、多少条/多少样本、时间跨度、纳入排除标准。
  设计数字须分解（如 90 组合 = 9 宿主系 × 10 病毒株 ≠ 90 个独立基因型样本）。
- [ ] **"ICC 双分母"陷阱**（v2.1.0 强制新增，源自进化生物档案）：同一个 ICC/方差
  占比数字，分母不同含义完全不同——ICC=0.34 是占**表型方差**（含环境噪声）的比例，
  而"63%"是占**遗传方差**（已扣除环境项）内份额；"88% of genetic variance" 对应的
  ICC 可以只有 0.082。引用任何 ICC/方差占比必须先抄录其分母口径并锚定页码；
  两口径数字不可互换或混比。
- [ ] **抽样框架偏差**（v2.1.0 新增，源自进化生物档案）：样本选择是否围绕已知
  位点/极端表型偏斜？亚分析中效应量骤变（如宿主主效 47%→35% 直至低于交互项）是
  抽样框架偏斜的信号——宿主系围绕已知抗性位点遴选时，主效估计对亚集选择极端
  敏感，外推到自然种群前必须核对选样框架。
- [ ] **模型假设**：统计/算法模型隐含假设是否声明（独立性、平稳性、无混杂…）。
- [ ] **方差分解是统计关联而非因果机制**：把方差拆成主效/交互只刻画统计结构；
  "模拟与实验一致"（如 80% 参数组合与野外估计重叠）是一致性论证，不构成对机制
  的直接检验；因果声明须有干预实验。
- [ ] **验证设计**：训练/测试划分、交叉验证、外部验证集——只有内部拟合的结论降级。
- [ ] **基准与消融**：是否与已有方法比（baseline）、是否做了消融（ablation）。
- [ ] **多重检验**：做了多少次检验、如何校正（FDR/Holm/Bonferroni）。
- [ ] **观察 vs 实验**：观察数据只能支撑关联声明；因果声明须有干预/自然实验设计。
- [ ] **不可估参数诚实性**：作者对 SE 大到无法解读的估计（rg=0.17±0.46 "too
  imprecisely estimated to interpret"）是否如实声明——如实声明的论文可信度加分。
- [ ] **可复现资产**：代码/数据可用性声明（Zenodo/OSF DOI、序列入库号）；随机
  种子/软件版本；AI 工具使用披露（2026 年起常见）。
- [ ] **鲁棒性**：换数据集/参数/模型设定结论是否稳定（敏感性分析）。

## 外行高发误读（跨学科读者）
1. 把模型预测精度当成现象解释力（高 R² ≠ 机制正确）。
2. 把关联挖掘结果当因果关系（尤其宿主-病原、基因-性状类研究）。
3. 忽略数据偏差来源（数据库覆盖偏差、抽样框架偏斜）对结论的影响。
4. 把模拟参数当实测值；把合成基准当真实场景；把"参数组合与野外估计重叠"当机制验证。
5. 混淆"提出方法"与"验证方法"——许多论文只做了前者。
6. ICC/方差占比不看分母口径直接引用，跨口径比较数字。

## 页码锚点要求
数据集描述、核心结果表、**ICC/方差占比的分母口径句**、验证/鲁棒性段落各至少 1 个锚点。
