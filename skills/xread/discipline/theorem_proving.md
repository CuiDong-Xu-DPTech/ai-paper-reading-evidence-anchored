# D1 定理证明型论文检查单

适用：数学、理论计算机、数理统计、理论物理的形式化部分。
论证正确性判据：**证明完整性**（每个断言都被证明或显式标注为假设/引用）。

## 强制核查项（逐项过，写入对齐表"学科规范项核查"列）
- [ ] **主定理完整抄录**：编号 + 陈述（含所有量词与条件）。条件与结论必须分开转述，禁止"证明了X"而隐去"在条件Y下"。
- [ ] **证明策略骨架**（v2.1.0 强制新增）：主定理的证明路线必须显式写出并锚定页码——
  (a) 化归到什么？把新问题化归为哪类已知问题/已有理论；
  (b) 用什么技术桥接？如张量幂/Kronecker 幂构造把多变元问题化归到单变元已有理论、
  归纳/对角化/紧性论证/消失定理/代数无关性…；桥接构造在文中哪一节完成。
  只写"证明了定理 X"而不写化归路线 = 核查不合格。
  依据：双评委盲测 4/4 报告全部漏掉 paper_M p42 的张量幂/Kronecker 幂化归策略（GM3 全失）。
- [ ] **假设清单**：论文依赖哪些定义、公理、已有定理（引用式证明须记录出处编号与页码）。
- [ ] **证明状态标注**：每个关键引理是"本文证明/引用他人/推迟到附录/悬而未决"。
  特别注意 "proof postponed"、"proved in Appendix"、"we claim"（claim ≠ 已证完）。
- [ ] **证明依赖链**：主定理 ← 关键引理 ← 已知结果逐层标注页码；判定算法可能在引文
  而非本文（如"算法在 [9] 而非本文"），引用式环节须注明文献编号。
- [ ] **记号依赖**：首次出现的记号在何处定义（页码）；同一符号或近形词（如两处
  "regular"）在不同章节是否含义变化。
- [ ] **新概念 vs 已知概念**：核心对象是本文新定义还是沿用文献？沿用则注明原出处。
- [ ] **强度声明**：作者是否声称"first/optimal/sharp"？这类词须核对正文证据位置。

## 外行高发误读（跨学科读者）
1. 把定理的条件当成结论或反之；量词顺序读反导致适用范围误判。
2. 把例子/特例/数值验证当成一般证明。
3. 只看定理陈述不追化归路线：把"排除性/刚性结果"误当"构造性算法"；把渐近性质
   误用于有限对象（定理覆盖无限数位序列，不直接适用于有限字符串/数据）。
4. 把"我们相信/预期"（conjecture）与作者自认 open（"out of reach"）当已证结果引用。

## 页码锚点要求
定理陈述、关键定义、**证明策略骨架（化归/桥接构造所在页，如张量幂构造页）**各至少
1 个锚点；证明细节抽查 2 处（引理或步骤）。
